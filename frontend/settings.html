Model providers

Use your own API key

By default your builds run on Souqi's own models. Add a key below and that provider becomes selectable in the agent's model picker, next to Eco Souqi and Powered Souqi — builds then run on your account, billed by that provider directly, and are not counted against your Souqi usage.

How your keys are stored

Keys are encrypted before they are written to the database and are never sent back to the browser — this page only ever shows the last four characters of what you saved. Remove a key here and it is deleted outright; there is no copy kept.
